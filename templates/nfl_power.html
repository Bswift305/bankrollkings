How to read it honestly: this is an Elo rating — it only ever moves on game results (who beat whom, by how much), never on a betting line, so it’s a clean yardstick to compare the market to. 1500 is league-average; the gap between two teams’ numbers is a strength gap, not a point spread. We only show NFL here because its model actually beat a coin flip picking winners out-of-sample — the same engine is gated OFF for sports where it didn’t (e.g. MLB), so we never wave around an “edge” we can’t back up.
