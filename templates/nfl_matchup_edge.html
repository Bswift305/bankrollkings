How to read it honestly: this is the own-data version of a “vs man coverage” note. We don’t license proprietary man/zone charting, so instead of claiming a coverage split we can’t source, we pair what a player does with the matching opponent rank: a receiver’s usage + separation (NGS) vs the pass defense; a back’s carry share vs the run defense; a rusher’s pressure rate vs the pass protection. Opponent rank is always 1 = toughest, 32 = softest, so a high-usage player into a soft matchup (a PLUS SPOT) floats to the top; the edge number weighs skill, volume and matchup together.
